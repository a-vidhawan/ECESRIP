## Implementation Path

1. **Start from sim/rtl/**: The RTL generated by the pipeline (`hopfield_top.sv`, `neuron_logic_bank.sv`) is the synthesis target
2. **Target board**: TBD (likely Artix-7 or Zynq-based dev board)
3. **Synthesis tool**: Vivado (script at `sim/scripts/synth_vivado.tcl`)
4. **Constraints**: Timing is asynchronous — no clock constraint for neuron combinational loops. Clock needed only for I/O interface and state register updates.

---

## Key Design Decisions (TBD)

- **Clocked vs fully async**: Fully async is novel but harder to validate. Clocked registered version is safer to start.
- **Sparse connectivity**: For N > 16, choose F strongest weights per neuron, reducing truth table from 2^N to 2^F rows.
- **BRAM vs distributed LUT**: Small N (≤12) fits distributed LUTs. Larger N may use BRAM as addressed ROM.
- **Feedback timing**: How to handle asynchronous feedback without oscillation or metastability?

## Resource Estimates (Artix-7, LUT6)

| N | LUTs per neuron (worst case) | Total LUTs (N neurons) |
|---|---|---|
| 8 | ~20-50 | ~200-400 |
| 10 | ~50-100 | ~500-1000 |
| 12 | ~100-200 | ~1200-2400 |
| 14 | ~200-500 | ~2800-7000 |
| 16 | ~500-1000 | ~8000-16000 |

Actual LUT count depends on how well Espresso minimizes each neuron's SOP. Neurons trained on random patterns with M near 0.14N tend to have roughly half-1 truth tables (balanced ON/OFF sets), which minimizes moderately well.
